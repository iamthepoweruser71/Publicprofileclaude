## 🚀 Deployment Instructions

### Option 1: GitHub Pages (Recommended - Free)

1. **Create GitHub Account**
   - Visit [github.com](https://github.com)
   - Sign up for free account

2. **Create New Repository**
   - Click "+" icon → "New repository"
   - Name: `kumar-abhinav-portfolio`
   - Select "Public"
   - Click "Create repository"

3. **Upload Files**
   - Click "uploading an existing file"
   - Drag and drop all files
   - Commit changes

4. **Enable GitHub Pages**
   - Go to Settings → Pages
   - Source: "Deploy from a branch"
   - Branch: `main` → `/ (root)`
   - Save

5. **Access Your Site**
   - Wait 2-3 minutes
   - Visit: `https://YOUR-USERNAME.github.io/kumar-abhinav-portfolio/`

### Option 2: Custom Domain (Optional)

1. Purchase domain from Namecheap, GoDaddy, etc.
2. Add DNS records:
   ```
   Type: A
   Host: @
   Value: 185.199.108.153
   
   Type: A
   Host: @
   Value: 185.199.109.153
   
   Type: CNAME
   Host: www
   Value: YOUR-USERNAME.github.io
   ```
3. In GitHub Settings → Pages → Custom domain
4. Enter your domain name
5. Enable "Enforce HTTPS"

## 🆘 Troubleshooting

### Site Not Loading?
- **Check:** GitHub Pages enabled in Settings
- **Verify:** Repository is Public
- **Wait:** 5 minutes for deployment
- **Clear:** Browser cache

### Images Not Showing?
- **Check:** File path is `./images/profile.jpg`
- **Verify:** File extension matches (jpg vs jpeg vs png)
- **Confirm:** Images folder exists in repository
- **Test:** Image file size < 500KB

### Mobile Menu Not Working?
- **Clear:** Browser cache
- **Test:** Incognito/Private mode
- **Check:** JavaScript console for errors
- **Verify:** Internet connection

### Cookie Banner Not Appearing?
- **Clear:** LocalStorage
- **Delete:** Cookies
- **Refresh:** Page (Ctrl/Cmd + Shift + R)
